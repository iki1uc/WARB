# WARB — Tiefe (T)

WARB ist die Tiefenachse des iki1uc‑Systems.  
Sie bildet die untere GEO‑Rotation und verbindet die Matrix‑Stationen  
mit den Tiefenachsen TMP‑γ.

WARB ist die 5. Station im 9‑Stations‑System:

1. HY  
2. PE  
3. PER  
4. TRANS  
5. **WARB**  
6. KANAL  
7. TMP‑α  
8. TMP‑β  
9. TMP‑γ

---

## GEO‑Segmente

WARB nutzt die Tiefen‑Sequenz:

81 → ◆ → △ → 27


Diese Segmente stammen aus:

- geo-form-kompatibel-mit-3.csv  
- WARB/GEO.md  
- WARB/WARB.md

Bedeutung:

- 81 = Raum  
- ◆ = Prüfung  
- △ = Funktion  
- 27 = Tiefe  

WARB ist die **tiefe Prüfung im Raum**.
