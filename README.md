# WARB — Tiefe (T)

## Zweck
WARB ist die Tiefenachse des iki1uc-Systems.
Sie analysiert Respo-Werte, erzeugt Tiefe und bereitet den Übergang
zum normalen Geschäft vor.

## Funktionen
- Tiefe (T) berechnen
- Respo.next analysieren
- NC.vector vorbereiten
- Stabilität prüfen
- Nevada-State ermöglichen
